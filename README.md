# Nonlinear Story Game

An interactive story game built around the concept of **nonlinear storytelling**, where the player's decisions influence how the story develops.

Instead of following one fixed storyline from beginning to end, the game allows players to make choices that lead them down different paths and toward different outcomes.

The repository contains multiple iterations of the game, documenting the evolution of the story, gameplay, and overall experience.

## 🎮 Features

- 📖 Interactive storytelling
- 🔀 Branching narrative paths
- 🧭 Player-driven choices
- 🎯 Multiple possible outcomes
- 🌐 Browser-based gameplay
- 🎨 Interactive web interface
- 🧩 Multiple versions and iterations
- 💡 Focus on nonlinear narrative design
