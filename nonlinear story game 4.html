StoryForge Pro - User Guide

                
            

            

                
🎯 Getting Started

                
Create interactive stories with branching narratives using our visual node editor.

                
                
📝 Node Types

                
    
                    
  • Story Node: Contains narrative text
    • 
                    
  • Choice Node: Presents player options
    • 
                    
  • Condition Node: Logic-based branching
    • 
                    
  • End Node: Story conclusion
    • 
                

                
                
🔗 Connections

                
Click and drag between connection points to link nodes. Green points are outputs, red points are inputs.

                
                
⌨️ Shortcuts

                
    
                    
  • Delete: Remove selected node
    • 
                    
  • Ctrl+S: Save project
    • 
                    
  • Ctrl+Z: Undo (coming soon)
